## [프로젝트 설명]
<img width="700" alt="image" src="https://github.com/user-attachments/assets/f0033a21-e774-4920-a1bb-75bdd55df7b2">

- 카메라를 통해 손가락을 인식하는 Virtual drawing을 통한 간단한 스케치 그림을 생성
- 텍스트와 함께 스케치 그림을 전송
- AI 모델을 통해 고퀄리티의 이미지를 생성
<br>
<br>

## [프로젝트 기술 설명]

### 웹 통신
- Ngrok, Flask, Google Colab
### 웹 페이지 디자인
- HTML, CSS, JavaScript
### 영상 처리
- openCV, mediapipe
### AI 이미지 생성
- Stable diffusion(pretrained Controlnet-scribble) + Controllnet
